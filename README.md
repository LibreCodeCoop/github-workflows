# github-workflows

This repository has been retired.

Active responsibilities moved to their natural owners:

- **Release product:** [LibreCodeCoop/release-tool](https://github.com/LibreCodeCoop/release-tool)
- **Organization workflow catalog, synchronization, and organization-level helper Actions:** [LibreCodeCoop/.github](https://github.com/LibreCodeCoop/.github)

Consumer repositories should use materialized workflow YAML from the organization catalog and pin Release Tool Actions to immutable commits from published Release Tool versions.

No active workflow, Action, release runtime, template, synchronization path, or compatibility layer is maintained here. The Git history remains available for audit and migration archaeology.

See the destination repositories for current documentation, issues, and implementation.
